# COLORS

COLORS is a simple full-stack web application built using the LAMP stack. Users can log in, add colors, and search through their saved colors.

## Technologies

HTML, CSS, JavaScript, PHP, MySQL, Apache, Linux

## Setup

1. Set up a LAMP environment.
2. Create and configure the MySQL database.
3. Add your database credentials to the PHP API files.
4. Place the project files in the Apache web directory.
5. Open the application in a browser.

## Assumptions and Limitations

- Requires a configured LAMP environment and MySQL database.
- Database credentials are not included in this repository.
- This project was created as a basic demonstration of a full-stack LAMP application.
